## 13. 심사 대응

> 2026-09-12 전면 개정. 근거는 [`product-identity.md`](product-identity.md) §5·§8.

### 13.1 예선 기준 매핑

| 기준 | 대응 |
|---|---|
| 기획력 | "우리가 좋은 집을 골라준다"(주관·반박 가능)를 버리고 **"당신이 고른 집들을 같은 자로 재서 보여준다"**(객관·방어 가능)로 전환 |
| 실현 가능성 | 배포 URL 확보를 계획한다. 서울 전역 9,160단지 실데이터를 정적 배포로 제공하고, 무료 티어 내 운영을 계획한다 |
| 확장성 | 빌드 타임 사전계산 구조. 동일 엔진으로 지역·매물유형 확장. 규제 정보의 주기 자동 갱신은 후속 구현 계획이다 |
| AI 활용 적절성 | 물리 시뮬레이션 + LightGBM. **SHAP는 쓰지 않는다** — 상관된 feature의 attribution은 배경 설정에 좌우된다 |

### 13.2 제출에 쓸 수 있는 숫자 셋

다음 수치는 평가 설계와 남은 한계를 함께 명시해서 쓴다. 특히 cold-start의 9.73%는 모델선택용 단지 holdout 결과이며, cold-start rolling-origin 첫거래 평가는 아직 하지 않았다.

1. **30.3의 단지 이력 부재 평가 거래 4.52%에서 B2 global-mean fallback MAPE 64.65%와 탐색 모델 M3 MAPE 21.16%를 비교했다.** 별도 모델선택용 단지 holdout에서는 전세 feature 채택으로 12.65% → 9.73%였다. 다만 추정 대상의 72.8%는 ≤20세대이고, 이 구간은 전세 추가 후 17.03% → 17.78%로 악화됐다.
2. **이 사양·이 평가기간에서 물리 feature의 추가 예측 개선을 확인하지 못했다.** M2 대비 M3 out-of-time MAPE 차이의 bootstrap 95% CI는 [-0.039, +0.105]%p로 0을 포함한다.
3. **서비스 가격 셀은 rolling OOT로도 검증했다.** 2026-02~07 다음 달 거래의 transaction-weighted MAPE는 score 가능한 전체에서 7.75%이며, `CELL_LAST` 실거래 셀 route는 대상의 89.2%, MAPE 7.48%였다.
4. **결함을 스스로 찾아 고친 이력.** 지역 FE가 68개 범주로 뭉개져 역삼동과 미아동이 같은 지역이던 것, 검증 기간 가격으로 이상치를 제거하던 누수, in-sample 잔차로 만든 거짓 예측구간 — 전부 적대적 리뷰로 잡아 재측정했다

**폐기한 주장**: "한강 조망 +30.9%"(현재 train M3 사양의 조건부 연관은 +6.0276% [3.0331, 9.1091]), "물리 feature ΔR² +0.079"(현재 +0.0021). 둘 다 지역 통제 결함에서 나온 값이었다.

### 13.3 온라인 투표(20%)

- 단지별 딥링크 공유 유도
- **서울 전역 커버 → 누가 검색해도 결과가 나온다**

### 13.3 본선 발표 구성 (예선 통과 후 준비)

빈 지도에서 시작하지 않는다. 실제 후보 비교로 연다.

1. (0~15초) **시연 — 관심 단지 3곳을 담는다 → 비교서**
2. (15~40초) 가격: 실거래는 실거래로, 거래 없는 단지는 "추정 + 구간 + 근거 사례"로 **라벨이 다르게** 나간다
3. (40~70초) 환경: 일조·조망·역·학교를 같은 축에 나란히. **가격과 엮어 말하지 않는다**
4. (70~100초) 기술: horizon 엔진 단일 연산에서 지표 파생 + cold-start에서 전세 feature 채택 시 단지 holdout MAPE 12.65%→9.73%; 서비스 실거래 셀 rolling OOT는 대상 89.2%, MAPE 7.48%
5. (100~130초) **정직성 — 이 사양·이 평가기간에서 물리 feature의 추가 예측 개선을 확인하지 못했다.** 결함 셋을 스스로 찾아 고친 이력
6. (130~150초) 확장
