# 지도 기반 웹 UI 디자인 테마 가이드

## 1. 디자인 테마 개요

이 디자인은 **지도 기반 탐색 경험을 중심으로 한 모던 SaaS형 인터페이스**를 지향한다.  
전체적으로는 복잡한 위치·상태 정보를 다루면서도 사용자가 부담 없이 탐색할 수 있도록, **차분한 음영 컬러 위에 선명한 단일 포인트 컬러와 카드형 정보 요소를 배치하는 방식**이 특징이다.

핵심 이미지는 다음과 같이 정의할 수 있다.

> **“정돈된 도시 데이터 위에, 필요한 정보만 선명하게 부각되는 위치 기반 서비스”**

시각적으로는 기술적이고 데이터 중심적이지만 차갑거나 무겁지 않으며, 예약·검색·모니터링·시설 탐색 등 **실용적인 위치 기반 서비스에 적합한 친근한 디지털 제품 분위기**를 형성한다.

---

## 2. 전체 무드

### Clean & Functional
불필요한 장식을 최소화하고, 기능과 정보 전달을 중심으로 구성한다.  
UI 요소는 단순하지만 지나치게 플랫하지 않고, 카드·버튼·선택 상태 등을 통해 사용자가 현재 무엇을 보고 있는지 명확하게 인지할 수 있도록 한다.

### Calm Technology
강한 미래지향적 연출보다는 **신뢰감 있는 디지털 서비스**의 이미지를 강조한다.  
지도, 데이터, 검색 조건 등 정보량이 많은 화면에서도 시각적 긴장감을 낮추기 위해 낮은 채도의 배경과 충분한 여백을 활용한다.

### Guided Exploration
사용자가 넓은 공간을 자유롭게 탐색하되, 중요한 위치·선택 상태·행동 유도 요소는 명확하게 강조한다.  
즉, “자유 탐색”과 “서비스가 추천하는 다음 행동”이 함께 존재하는 UX를 목표로 한다.

## 3. 핵심 시각 특징

### 3.1 단일 톤 컬러 시스템

전체 화면은 흰색과 음영 컬러 `#F6F7F9`를 기본으로 한다.  
그 위에 포인트 컬러 `#4136E8` 하나를 사용해 다음 요소를 강조한다.

- 현재 선택된 위치
- 주요 행동 버튼
- 활성화 상태
- 지도상의 중요 영역
- 서비스가 추천하는 정보

여러 강조색을 동시에 쓰지 않고 **`#4136E8` 하나를 중심으로 집중도를 높이는 방식**을 원칙으로 한다. 상태 구분이 필요한 경우에도 초록, 주황, 빨강 계열을 새로 만들기보다 포인트 컬러의 투명도, 테두리, 배경 농도, 회색 톤, 텍스트 라벨로 구분한다.

권장 토큰:

```text
point color: #4136E8
shade color: #F6F7F9
surface: #FFFFFF
text: #1D2433
sub text: #697386
line: #E1E4EA
```

---

### 3.2 지도는 배경이 아니라 핵심 데이터 레이어

지도는 단순한 배경 이미지가 아니라 서비스의 주요 인터페이스로 취급한다.  
다만 도로명, 건물명, 지형 정보가 지나치게 강하게 보이지 않도록 **낮은 명도 대비와 저채도 스타일**을 적용해, 실제 서비스 정보가 더 먼저 인지되도록 한다.

지도 위의 서비스 정보는 다음과 같이 처리한다.

- 위치 포인트는 작지만 명확한 시각적 강조
- 선택 지점은 일반 지점보다 강하게 표현
- 탐색 반경, 영향권, 서비스 가능 범위는 반투명 면으로 표현
- 위치 설명은 지도와 분리된 카드형 오버레이로 제공

즉, **지도 자체보다 지도 위에 얹히는 의미 정보가 더 중요하게 보이는 구조**를 지향한다.

---

### 3.3 카드 기반 정보 구조

위치별 세부 정보는 하나의 독립된 정보 단위로 인식될 수 있도록 카드 형태로 표현한다.  
카드는 복잡한 데이터를 한 번에 보여주기보다는, 사용자의 의사결정에 필요한 핵심 정보만 우선적으로 제공한다.

카드 디자인의 성격은 다음과 같다.

- 밝은 배경
- 얇은 경계선 또는 매우 약한 그림자
- 부드러운 모서리
- 충분한 내부 여백
- 짧고 명확한 정보 그룹
- 필요 시 작은 태그 또는 상태 표시

이를 통해 지도 위 또는 주변에 정보가 많이 존재하더라도 **각 정보 단위의 경계를 명확히 유지**한다.

---

## 4. 형태 언어

전체적인 형태는 **직선적 구조와 부드러운 모서리가 결합된 형태 언어**가 적합하다.

너무 둥글고 캐주얼한 모바일 앱 스타일보다,  
기본 구조는 정제된 사각형을 유지하면서 모서리에 적당한 라운드를 부여해 전문성과 친근함 사이의 균형을 만든다.

권장되는 형태적 특성은 다음과 같다.

- 카드와 입력 요소: 10~12px 수준의 낮은 라운드
- 버튼: 10~15px 수준의 낮은 라운드
- 지도 포인트: 원형 또는 단순한 핀 형태
- 범위·영역 표현: 부드러운 반투명 원 또는 면
- 아이콘: 얇고 단순한 라인 아이콘

---

## 5. 정보 표현 방식

### 정보의 우선순위를 명확하게 구분

모든 데이터를 동일한 시각적 강도로 보여주지 않는다.  
사용자의 의사결정과 직접 연결되는 정보에 가장 높은 대비를 부여하고, 부가 정보는 한 단계 낮은 대비로 표현한다.

예를 들어 다음과 같은 위계를 유지한다.

**핵심 정보**
- 장소명
- 주요 상태
- 거리 또는 위치
- 핵심 행동

**보조 정보**
- 편의시설
- 세부 속성
- 운영 상태
- 추가 설명

**참고 정보**
- 세부 주소
- 부가 메타데이터
- 기타 옵션

이러한 정보 계층을 통해 사용자는 화면을 자세히 읽지 않아도 **시각적 스캔만으로 중요한 정보를 파악할 수 있어야 한다.**

## 6. 상태 표현

위치 기반 서비스에서는 ‘선택됨’, ‘이용 가능’, ‘추천’, ‘제한’ 등의 상태가 중요하므로 이를 색상과 형태로 명확하게 구분한다.

상태 표현은 큰 배지보다 **작은 태그, 아이콘, 미세한 컬러 변화**를 활용하는 것이 적합하다.

예:

- 선택 상태 → `#4136E8` 테두리 또는 연한 포인트 배경 강조
- 정상/이용 가능 → 작은 포인트 컬러 인디케이터
- 제한/주의 → 회색 톤과 텍스트 라벨
- 비활성 → 낮은 명도와 대비

중요한 원칙은 색상만으로 상태를 전달하지 않고, 텍스트·아이콘·형태를 함께 활용하는 것이다.

---

## 7. 타이포그래피

타이포그래피는 개성이 강한 서체보다 **가독성이 높은 산세리프 계열**이 적합하다.

전체 인상은 다음을 목표로 한다.

- 제목: 명확하고 단정함
- 본문: 작은 크기에서도 높은 가독성
- 보조 정보: 낮은 대비
- 숫자·거리·시간: 빠르게 읽히는 구조

타이포그래피는 장식적 역할보다 **정보 계층과 스캔 속도를 높이는 도구**로 활용한다.

---

## 8. 여백과 밀도

지도 기반 UI는 정보량이 많기 때문에, 요소를 크게 만드는 것보다 **정보 그룹 사이의 간격을 명확하게 확보하는 것**이 중요하다.

전체적으로 다음과 같은 밀도를 지향한다.

- 화면 전체는 비교적 넓고 여유롭게
- 카드 내부는 중간 수준의 정보 밀도
- 핵심 행동 주변은 충분한 여백 확보
- 보조 정보는 작고 간결하게 정리

이를 통해 데이터가 많은 서비스에서도 복잡한 인상을 최소화할 수 있다.

---

## 9. 인터랙션 분위기

인터랙션은 화려한 애니메이션보다 **즉각적이고 안정적인 피드백**을 중심으로 한다.

권장되는 인터랙션은 다음과 같다.

- 지도 포인트 선택 시 자연스러운 강조
- 선택 카드와 지도 포인트의 동기화
- Hover 시 가벼운 배경 또는 테두리 변화
- 선택 범위는 부드럽게 나타나는 반투명 오버레이
- 검색 또는 필터 변경 시 결과가 빠르게 갱신되는 느낌

전체적으로 사용자가 “지금 무엇을 선택했고 무엇이 변경되었는지”를 즉시 이해할 수 있어야 한다.

## 10. 브랜드 인상

이 디자인 테마가 전달하는 브랜드 이미지는 다음과 같다.

- **신뢰할 수 있는**
- **데이터 기반의**
- **도시적이고 현대적인**
- **정돈된**
- **빠르고 효율적인**
- **사용자 중심의**
- **전문적이지만 어렵지 않은**

특히 지도 기반의 B2B SaaS, 모빌리티, 헬스케어 시설 검색, 상권 분석, 부동산, 물류, 스마트시티, 시설 관리 서비스 등에 자연스럽게 적용할 수 있다.

---

## 11. 디자인 적용 원칙

이 테마를 다른 서비스에 적용할 때는 특정 화면의 배치를 복제하기보다 아래 원칙을 유지하는 것이 중요하다.

1. **지도·공간 정보를 가장 큰 시각적 맥락으로 사용한다.**
2. **서비스 정보는 지도와 시각적으로 명확하게 분리한다.**
3. **포인트 컬러 `#4136E8`은 선택과 행동 유도에 집중적으로 사용한다.**
4. **정보는 카드 또는 명확한 그룹 단위로 구조화한다.**
5. **지도 자체는 저채도로 유지해 서비스 데이터가 우선적으로 보이게 한다.**
6. **많은 정보를 보여주더라도 화면 전체는 가볍고 정돈된 인상을 유지한다.**
7. **선택 상태와 공간적 범위는 시각적으로 즉시 파악할 수 있도록 표현한다.**

## 12. 한 문장 디자인 정의

> **저채도의 지도와 정돈된 정보 카드를 기반으로, 선명한 포인트 컬러를 통해 위치·선택·행동을 직관적으로 강조하는 모던 위치 기반 SaaS 디자인 테마.**
