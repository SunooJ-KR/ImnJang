## 1. 한 줄 정의

> **관심 있는 아파트를 직접 담아서 같은 기준으로 나란히 비교하는 서비스.**

서울 9,160단지의 거주 환경을 물리 시뮬레이션과 공공데이터로 미리 계산해 두고,
사용자가 고른 단지들을 동일한 축에서 재어 보여준다.

## 2. 이전 정의에서 무엇이 바뀌었나

| | 이전 | 현재 |
|---|---|---|
| 한 줄 정의 | 서울 9,000단지를 살기 좋은 순서로 정렬하는 지도 | 고른 단지를 같은 기준으로 비교하는 서비스 |
| 주인공 | 일조·조망 정렬 | 비교서 (가격 근거 + 환경 차이) |
| 시세 모델 | Layer 2 / D9 / 생략 가능 | **주 산출물**. 단, 역할 한정 (§5) |
| 지도·필터 | 제품의 약속 | 단지를 **찾는** 보조 수단 |
| 포지셔닝 | 임장 대체 | 임장 전 비교 |

**"골라준다"에서 "고른 걸 비교해준다"로 바뀐 이유**: 무엇이 좋은 집인지는 사람마다 다르고,
우리가 정렬 순서로 그것을 단정하면 반박 가능한 주관이 된다. 사용자가 고른 대상을 같은 자로
재는 것은 객관적이고 방어된다.

**"임장 대체"를 버린 이유**: 향·호수·소음·실내 상태·실제 보행 동선·매물 가용성을 우리는 모른다.
대체한다고 말하는 순간 거짓이 된다.

## 3. 약속하는 것 / 하지 않는 것

| 약속한다 | 하지 않는다 |
|---|---|
| 이 단지의 환경이 어떤지 (일조·조망·교통·교육·의료·상권) | "좋은 집"이라는 종합 판정 |
| 이 단지가 최근 얼마에 거래됐는지 (5년 추이 포함) | 지금 살 수 있는 매물 가격(호가) |
| 비슷한 조건의 다른 단지는 보통 얼마인지 | 저평가/고평가 단정 |
| 왜 그렇게 보이는지의 근거 거래 목록 | 미래 가격·수익률 전망 |
| 현장에서 확인해야 할 항목 | 임장 자체의 대체 |
| 이 단지에 걸린 규제 (토지거래허가·재건축 추진) | 규제가 앞으로 어떻게 바뀔지 |

## 4. 동선

```
S1  검색 / 지도에서 관심 단지를 찾는다
S2  비교 대상으로 담는다 (2~4곳)
S3  비교서
     ├─ 가격 : 각 단지의 최근 실거래 + 5년 추이. 거래 없으면 추정 + 구간
     ├─ 환경 : 일조·조망·역·학교·병원·상권을 같은 축에 나란히
     └─ 현장 확인 : 데이터로 못 아는 것 (향·호수·소음·실내 상태)
```

기존 지도·필터·정렬 자산은 S1에서 그대로 쓴다. 버리지 않되 제품의 약속으로 내세우지 않는다.

## 5. 가격 기능 — baseline-first

### 5.1 설계

```
1. 동일 단지 × 면적타입 × 층대의 최근 거래가 있는가?
   └─ 있다                 →  그 실거래가를 그대로 표시. 모델을 쓰지 않는다
2. 없다면, 같은 단지의 다른 거래가 있는가?
   └─ 있다                 →  단지 평균을 표시. 모델을 쓰지 않는다
3. 단지 이력이 아예 없는가?
   └─ 그렇다               →  모델 추정 + 구간 + 근거 거래사례를 함께 표시
```

2번까지가 모델을 이긴다. **모델이 정당한 구간은 3번뿐이다.**

모델이 쓰인 구간은 화면에 **"추정"**으로 라벨이 다르게 붙는다. 감추지 않는다.

### 5.2 이 설계의 근거 (실측)

최근 24개월 매매 실거래로 out-of-time 검증. 학습 2024-09~2026-02 / 검증 2026-03~2026-08.
이상치 컷오프는 학습 기간 가격으로만 계산했고 검증 행은 가격 기준으로 제거하지 않았다.

| 구간 | 비중 | 실거래 baseline MAPE | 모델 MAPE | 승자 |
|---|---|---|---|---|
| 동일 셀 직전 거래 있음 | 91.91% | **7.95%** | 18.46% | 실거래 |
| 동일 셀 없음 / 단지 평균 있음 | 3.57% | **14.64%** | 23.71% | 실거래 |
| **단지 이력 자체가 없음** | **4.52%** | 64.65% | **21.16%** | **모델 (+43.49%p)** |

아파트 가격은 자기상관이 극도로 강해, 같은 단지의 거래가 하나라도 있으면 어떤 모델도
그것을 못 이긴다. 모델의 정당한 역할은 **단지 이력이 전무한 cold-start 구간뿐**이며,
그 구간은 이 baseline 검증 거래의 4.52%다.

(상위 집계인 "동일 셀 직전 거래 없음" 8.09% 구간에서는 모델이 baseline을 20.27%p 앞서지만,
그 안을 갈라보면 우위는 전적으로 4.52%의 단지 이력 부재 구간에서 나온다. 8.09%를 모델의 영역이라고 말하면
과장이다.)

### 5.3 물리 feature의 추가 예측 개선을 이 사양·이 평가기간에서 확인하지 못했다

**초기 측정은 결함이 있었다.** 지역 통제에 쓰던 `bjd_code`가 법정동 코드 10자리 중 시군구를 뺀 5자리만 담고 있어, 고유값이 68개뿐이었고 그중 45개가 여러 자치구를 섞었다. 강남구 역삼동과 강북구 미아동이 같은 지역 범주였다. 자치구를 결합해 완전 법정동 키(324~335개)로 고친 뒤 전면 재측정했다.

| 모델 | ΔR² (결함 상태) | **ΔR² (수정 후)** |
|---|---|---|
| C. `river_view`만 | +0.0527 | **+0.0009** |
| D. `sun_hours_winter`만 | +0.0015 | **+0.0001** |
| E. 개방도 3종만 | +0.0090 | **+0.0006** |
| F. 물리 전체 | +0.0664 | **+0.0021** |
| G. complete-case | +0.0823 | **+0.0020** |
| H. 정비사업만 | +0.0533 | **+0.0133** |

기준 모델(M2)의 `log(price/m²)` train adj. R²는 **0.817496**이다. 이는 면적·연식·입지·지역 fixed effect를 함께 포함한 M2 전체 사양의 in-sample 적합도이며, 법정동 하나의 attribution으로 읽을 수 없다.

**결정적 수치 — 예측 개선이 0과 구별되지 않는다.**

```
M2 vs M3 out-of-time MAPE 차이 (단지 단위 block bootstrap 1,000회)
  결함 상태:  2.165%p   95% CI [ 1.73, 2.61]   0을 배제
  수정 후:    0.038%p   95% CI [-0.039, 0.105]  0을 포함
```

joint Wald는 여전히 유의하다 (F(9,6222)=13.81, p=3.07e-22). 즉 **통계적 연관은 있으나 예측을 개선하지 않는다.** 이 둘은 다른 문제다.

**33 서비스 가격 모델은 M2 + 정비사업 signal + 전세 feature이며, 물리 feature는 제외한다.** 물리 feature를 포함한 사양은 30의 ablation에서만 유지한다. 같은 split·채택 전세 사양에서 물리 feature 포함/제외 단지 holdout MAPE는 **9.853% → 9.728%**였다. 물리 feature의 M2 대비 OOT MAPE 개선 bootstrap 95% CI는 **[-0.039, +0.105]%p**로 0을 포함한다. 따라서 일조·조망은 가격 모델에서 빼고 환경 비교 화면 전용으로 쓴다.

### 5.5 cold-start 모델에 전세를 쓴다

최근 24개월 매매가 없는 단지 2,318개 중 **1,290개는 전세 거래가 있다**. 진짜 무거래는 3개뿐이다.
이 단지들은 세대수 중앙값 18세대(하위 25%는 12세대 이하)의 나홀로·소규모 단지로, 매매만 드물 뿐 실재하고 거래된다.

전세를 두 용도로 쓴다.

| 용도 | 효과 |
|---|---|
| **면적타입 발견** | 추정 가능 단지 1,025 → **2,315** (면적 미상 3단지만 남음) |
| **가격 feature** | 단지 holdout MAPE **12.65% → 9.73%** (전세 없음 J → 채택 L) |
| **최종 추정 대상** | 임대 전용 단지 제외 후 **2,206단지 / 6,028행** |
| **비교사례** | cold-start 커버리지 **87.5%** |

채택 L의 OOT MAPE는 **11.57%**, 단지 holdout MAPE는 **9.73%**다. 세대수 구간별 개선폭이 다르다. 101세대+는 12.46% → 9.37%로 줄지만, **≤20세대는 17.03% → 17.78%로 악화된다.** 정작 cold-start 추정 대상의 대부분이 그 구간이다.

과거 전세 trim은 셀×연도별 `floor(n×1%)` 건수로 통일했다. 이전 셀 cutoff의 제거율 약 21.0%는 PURE **0.193%**, CONVERTED **0.365%**로 낮아졌고, 두 사양 모두 하한·상한 제거가 50:50이다.

전세가 만드는 함정은 §9에 적었다 — 갱신계약 미구분, 신축 입주장, 역전세, 시점 불일치.

## 6. 표기 규칙 — 어기면 사실 왜곡

`data-contract.md` §6의 기존 규칙에 아래를 추가한다.

| 쓸 수 있다 | 쓸 수 없다 |
|---|---|
| "이 단지 이 면적의 최근 거래는 14.2억입니다" | "적정시세는 14.2억입니다" |

| "비슷한 조건 단지 5곳의 최근 거래는 12~15억입니다" | "이 집은 저평가입니다" |
| "일조가 가격에 미치는 영향은 확인되지 않았습니다" | "일조는 가격에 반영되지 않습니다" |
| "토지거래허가구역입니다 (2026-08-16 기준)" | 기준일 없이 "허가구역입니다" |
| "재건축 추진 중 (조합설립 단계)" | "재건축으로 N% 오릅니다" |

**일조에 대해 특히 주의한다.** p = 0.07766은 "효과 없음"의 증거가 아니라 "증거 없음"이다.
신뢰구간은 시간당 +0.97336%까지 열려 있어, 3시간 차이에서 약 +2.92% 프리미엄도 배제하지 못한다.
"시장이 일조에 값을 매기지 않으니 공짜로 얻으라"는 서사는 데이터가 뒷받침하지 않으므로 금지한다.

우리가 말할 수 있는 것은 여기까지다:

> 최근 실거래가는 가격의 가장 강한 기준점이다. 임앤장은 실거래가만으로 확인할 수 없는
> 일조와 조망을 물리적으로 계산해 주거 선택 정보를 보완한다.

## 7. 비교사례 제시 규칙

"비슷한 환경의 다른 곳은 보통 이 가격" 문장을 만들 때:

- 동일 단지 → 인근 유사 단지 순으로 찾는다. 면적·연식·규모·지역을 먼저 제한하고 환경 유사도는 그 다음이다
- **개수를 채우지 않는다.** 적합한 사례가 2곳이면 2곳만 보여준다
- 원 거래가·거래일·보정액·선정 이유를 함께 표시한다. 보정폭이 큰 사례는 제외한다
- 보정가격은 실제로 체결된 가격이 아니라는 것을 화면에 명시한다

## 8. 대회 제출에 쓸 수 있는 것

**폐기한 주장 두 개.** 초기 측정의 지역 통제 결함에서 나온 값이었다.

| 버린다 | 왜 |
|---|---|
| "한강 조망 +30.9%" | 현재 train M3 사양의 조건부 연관은 +6.0276% [3.0331, 9.1091]이다. 개별 매물의 인과적 조망 프리미엄으로 말할 수 없다 |
| "물리 feature ΔR² +0.079" | 실제는 +0.0021. 예측 개선은 0과 구별되지 않는다 |

**남는 것**

1. **전세 feature를 채택한 cold-start 모델의 단지 holdout MAPE는 9.73%, OOT MAPE는 11.57%다.** 단, ≤20세대에서는 17.78%이며, 이 평가값을 추정 대상 전체 성능으로 일반화하지 않는다(§9).
2. **이 사양·이 평가기간에서 물리 feature의 추가 예측 개선을 확인하지 못했다.** 지역 통제 후 bootstrap CI가 0을 포함했으므로, 가격 모델에서는 빼고 환경 비교 화면 전용으로 둔다.
3. **결함을 스스로 찾아 고친 이력.** 지역 FE가 68개 범주로 뭉개져 있던 것, 검증 기간 가격으로 이상치를 제거하던 누수, in-sample 잔차로 만든 거짓 구간 — 전부 적대적 리뷰로 잡아 재측정했다

**SHAP는 쓰지 않는다.** 상관된 feature의 attribution은 배경 설정에 좌우된다.

**런타임 생성형 AI는 0회를 유지한다.** 대회 요건에 의무가 없으므로 감점도 가점도 아니다. 기술력 축은 위 세 가지로 세운다.

**학습 기간 한가운데(2025-10-20)에 제도가 바뀌었다.** 계약월 더미가 일부 흡수하지만 이 시점 전후로 가격 구조가 달라졌을 가능성은 검증하지 않았다.

투기과열지구·조정대상지역은 국토부 고시라 별도 소스가 필요하며 아직 확보하지 않았다.

## 9. 알려진 한계

`data-contract.md` §7의 기존 한계에 더해:

| 한계 | 영향 |
|---|---|
| **물리 feature의 추가 예측 개선을 이 사양·이 평가기간에서 확인하지 못했다** | 지역 통제 후 bootstrap CI가 0을 포함했다(§5.3). 가격 모델에서 빼고 환경 비교 전용으로 쓴다 |
| 지역 FE 결함으로 초기 측정이 전부 틀렸다 | `bjd_code` 68개 범주가 자치구를 섞었다. 완전 법정동 키로 고쳐 재측정했으나, **같은 유형의 키 결함이 다른 곳에 남아 있을 수 있다** |
| **해결됨 — 서비스 셀 rolling OOT 도입** | 30.5는 단지×면적타입×층대 service route를 2026-02~07 rolling origin에서 다음 달 거래로 평가했다. score 가능한 전체의 transaction-weighted MAPE는 7.75%, `CELL_LAST` route는 대상의 89.2% 및 MAPE 7.48%다 |
| **해결됨 — 이상치 제거가 소표본 셀을 지운다** | 기존 1/99 분위 규칙의 16,222건 제거를 `floor(n×1%)` 건수 기준으로 바꿨다. 현재 매매 train은 101,837건 중 **62건**만 제거(101,775건)하며, 소표본 셀의 양 끝을 일괄 삭제하지 않는다 |
| **남은 검증 한계 — cold-start rolling-origin 첫거래 평가는 미실시** | 30.5는 서비스 route의 rolling OOT이나, cold-start 단지가 이후 처음 매매되는 시점을 rolling-origin으로 평가하지는 않았다 |
| conformal이 엄밀한 split conformal이 아니다 | calibration 단지와 모델 선택용 holdout 단지가 같고, calibration 잔차를 구한 모델과 배포 모델이 다르다. 게다가 첫 coverage 실패(70.92%)를 보고 방식을 바꿨으므로 이후 값은 **test 재사용**이다. "80% 보장"이 아니라 **"개발 기간에서 관측된 empirical coverage"**까지만 말할 수 있다 |
| 예측구간이 너무 넓다 | 예측값의 0.88~1.25배. 10억이면 8.8~12.5억이라 단지 간 우열 판정에 쓸 수 없다 |
| 전세 갱신계약 | 중앙값은 방어 장치가 아니다. 갱신이 과반이면 중앙값 자체가 갱신 수준에 앉는다. 서울부동산정보광장에 계약구분·갱신요구권 항목이 있어 확보 가능성을 확인해야 한다 |
| 전세 trim의 as-of 불일치 | 전세 trim은 target별 as-of가 아니라 `source_end`까지의 자료로 수행됐다. OOT target 기간 rent를 사용한 것은 아니지만, 이후 rent가 과거 rent의 생존 여부에 영향을 줄 수 있다 |
| `mountain_view` 부호 역전 | 외곽 proxy인지 실제 효과인지 미분리. 가격 설명에 쓰지 않는다 |
| 개방도 3종 다중공선성 (VIF 12.66, r −0.92) | 개별 계수 해석 불가 |
| `est_confidence=HIGH`의 물리 지표 의존 | 가격 입력에는 물리 feature를 쓰지 않지만, HIGH 판정은 여전히 물리 지표 유무에 의존한다 |
| 정비사업은 **재건축만** 매칭된다 | 재건축 구역 136/166(81.9%) vs 재개발 5/302(1.7%). 재개발 구역은 지번이 수백 개인데 원본에 대표 1개뿐이다. "재개발 구역 인접"은 이 데이터로 만들 수 없다 |
| 정비사업 미매칭 단지의 상태가 모호 | "구역이 아님"과 "대표 지번이 달라 매칭 실패"를 구분할 수 없다. 결측으로 두고 "재건축 추진 중" 표기만 한다 |
| 전세의 **갱신계약을 구분할 수 없다** | 전월세 API에 `contractType`·`preDeposit`이 없다. 갱신은 5% 상한에 묶여 시세보다 낮게 찍히므로 전세 기반 추정이 체계적으로 과소평가될 수 있다. 셀 대표값에 평균 대신 중앙값을 써 완화했다 |
| 소규모 단지는 **외삽**이다 | 학습 표본은 매매 거래가 있는 단지(세대수 중앙값 80)인데 추정 대상은 중앙값 18세대다. ≤20세대 구간 MAPE는 17.78%로 전체 holdout(9.73%)보다 높다. 이 구간은 신뢰도를 LOW로 강등한다 |
| **평가 모집단과 서비스 대상이 다르다** | OOT의 **95.48%**는 학습에서 본 단지인 반면, 추정 대상의 **72.8%**는 ≤20세대이고 holdout에서는 그 비중이 **1.88%**다. 따라서 cold-start 오차 약 10%와 coverage 약 84%를 추정 대상 전체 성능으로 말할 수 없다 |
| 단지 holdout의 가격 정제 후 분할 | 평가셋 16행(8단지, 0.075%)은 split 전에 수행한 가격 정제의 영향을 받았다 |
| 서비스 route 단지 동일가중 MAPE의 집계 방식 | 30.5의 9.19%는 거래별 APE를 먼저 단지 평균한 뒤 단지를 동일가중한 값이다. 거래 단위 MAPE와 같은 값으로 해석하면 안 된다 |
| feature 시점 불일치 | 지표는 2026년 현재 상태. 학습을 최근 24개월로 한정해 완화했으나 완전히 제거되진 않았다 |
| 호가 부재 | 지금 살 수 있는 가격은 알 수 없다. 실거래만 다룬다 |
