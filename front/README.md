# front

반응형 웹앱 (Next.js 15 + TypeScript + Tailwind + shadcn/ui). 모바일 우선.

**원칙: 런타임은 조회만 한다.** 지표는 전부 배치에서 사전 계산되며, 서비스 중 연산이나 LLM 호출은 없다 (`plan.md` §2 제약 1).

| 화면 | 내용 | 일정 |
|---|---|---|
| S1 | 지도 탐색 + 조건 필터링·정렬 — 차별점의 실체 | D6 |
| S2 | 단지 리포트 | D7 |
| S3 | 근거 상세 | D7 |
| S4 | 가중치 슬라이더 (선제 절단 대상 4순위) | D7 |

배포: Vercel · DB: Supabase(Postgres + PostGIS) · 지도: 카카오맵 JS SDK
**주의**: 카카오 앱에 배포 도메인을 등록해야 프로덕션에서 지도가 뜬다 (`plan.md` R8).
