## 1. 한 줄 정의

> **관심 있는 아파트를 직접 담아서 같은 기준으로 나란히 비교하는 서비스.**

서울 9,160단지의 거주 환경을 물리 시뮬레이션과 공공데이터로 미리 계산해 두고,
사용자가 고른 단지들을 동일한 축에서 재어 보여준다.

## 2. 이전 정의에서 무엇이 바뀌었나

| | 이전 | 현재 |
|---|---|---|
| 한 줄 정의 | 서울 9,000단지를 살기 좋은 순서로 정렬하는 지도 | 고른 단지를 같은 기준으로 비교하는 서비스 |
| 주인공 | 일조·조망 정렬 | 비교서 (가격 근거 + 환경 차이) |
| 시세 모델 | Layer 2 / D9 / 생략 가능 | **주 산출물**. 단, 역할 한정 (§5) |
| 지도·필터 | 제품의 약속 | 단지를 **찾는** 보조 수단 |
| 포지셔닝 | 임장 대체 | 임장 전 비교 |

**"골라준다"에서 "고른 걸 비교해준다"로 바뀐 이유**: 무엇이 좋은 집인지는 사람마다 다르고,
우리가 정렬 순서로 그것을 단정하면 반박 가능한 주관이 된다. 사용자가 고른 대상을 같은 자로
재는 것은 객관적이고 방어된다.

**"임장 대체"를 버린 이유**: 향·호수·소음·실내 상태·실제 보행 동선·매물 가용성을 우리는 모른다.
대체한다고 말하는 순간 거짓이 된다.

## 3. 약속하는 것 / 하지 않는 것

| 약속한다 | 하지 않는다 |
|---|---|
| 이 단지의 환경이 어떤지 (일조·조망·교통·교육·의료·상권) | "좋은 집"이라는 종합 판정 |
| 이 단지가 최근 얼마에 거래됐는지 (5년 추이 포함) | 지금 살 수 있는 매물 가격(호가) |
| 비슷한 조건의 다른 단지는 보통 얼마인지 | 저평가/고평가 단정 |
| 왜 그렇게 보이는지의 근거 거래 목록 | 미래 가격·수익률 전망 |
| 현장에서 확인해야 할 항목 | 임장 자체의 대체 |

## 4. 동선

```
S1  검색 / 지도에서 관심 단지를 찾는다
S2  비교 대상으로 담는다 (2~4곳)
S3  비교서
     ├─ 가격 : 각 단지의 최근 실거래 + 5년 추이. 거래 없으면 추정 + 구간
     ├─ 환경 : 일조·조망·역·학교·병원·상권을 같은 축에 나란히
     └─ 현장 확인 : 데이터로 못 아는 것 (향·호수·소음·실내 상태)
```

기존 지도·필터·정렬 자산은 S1에서 그대로 쓴다. 버리지 않되 제품의 약속으로 내세우지 않는다.

## 5. 가격 기능 — baseline-first

### 5.1 설계

```
1. 동일 단지 × 면적타입 × 층대의 최근 거래가 있는가?
   └─ 있다 (거래의 87.9%)  →  그 실거래가를 그대로 표시. 모델을 쓰지 않는다
2. 없다면, 같은 단지의 다른 거래가 있는가?
   └─ 있다 (6.3%)          →  단지 평균을 표시. 모델을 쓰지 않는다
3. 단지 이력이 아예 없는가?
   └─ 그렇다 (5.8%)        →  모델 추정 + 구간 + 근거 거래사례를 함께 표시
```

2번까지가 모델을 이긴다. **모델이 정당한 구간은 3번뿐이다.**

모델이 쓰인 구간은 화면에 **"추정"**으로 라벨이 다르게 붙는다. 감추지 않는다.

### 5.2 이 설계의 근거 (실측)

최근 24개월 매매 실거래로 out-of-time 검증. 학습 2024-09~2026-02 / 검증 2026-03~2026-08.
이상치 컷오프는 학습 기간 가격으로만 계산했고 검증 행은 가격 기준으로 제거하지 않았다.

| 구간 | 비중 | 실거래 baseline MAPE | 모델 MAPE | 승자 |
|---|---|---|---|---|
| 동일 셀 직전 거래 있음 | 87.9% | **8.58%** | 26.52% | 실거래 |
| 동일 셀 없음 / 단지 평균 있음 | 6.3% | **15.23%** | 28.19% | 실거래 |
| **단지 이력 자체가 없음** | **5.8%** | 70.30% | **23.26%** | **모델 (+47.0%p)** |

아파트 가격은 자기상관이 극도로 강해, 같은 단지의 거래가 하나라도 있으면 어떤 모델도
그것을 못 이긴다. 모델의 정당한 역할은 **단지 이력이 전무한 cold-start 구간뿐**이며,
그 구간은 전체 거래의 5.8%다.

(상위 집계인 "동일 셀 직전 거래 없음" 12.1% 구간에서는 모델이 baseline을 15.6%p 앞서지만,
그 안을 갈라보면 우위는 전적으로 5.8% 구간에서 나온다. 12.1%를 모델의 영역이라고 말하면
과장이다.)

### 5.3 물리 feature가 가격을 설명하는가 — ablation

동일 표본·동일 split. M2 = 기본 + 입지, M3 = M2 + 물리.

| 모델 | ΔR² vs M2 | ΔMAPE |
|---|---|---|
| B. 물리 데이터 **유무 지시자만** | +0.0002 | −0.01%p |
| C. `river_view`만 | +0.0513 | −1.56%p |
| D. `sun_hours_winter`만 | +0.0016 | −0.05%p |
| E. 개방도 3종만 | +0.0082 | −0.32%p |
| F. 물리 전체 | +0.0677 | −2.19%p |
| G. 평균대체 없는 complete-case | **+0.0791** | **−2.38%p** |

- **B가 사실상 0** → 개선이 "footprint 매칭에 성공한 단지"라는 선택 효과 때문이라는 의심은 기각됐다.
- **C / F = 75.8%** → 물리 feature 기여의 4분의 3이 한강 조망 하나다.
- M2 vs M3 out-of-time MAPE 차이의 단지 단위 block bootstrap 95% CI = **[1.75, 2.63]%p** (0 배제).
- 물리항 전체 cluster-robust joint Wald: F(9, 5774) = 23.46, p = 8.7e-40.

### 5.4 물리 계수의 실질 크기

| feature | 가격 변화 | 95% CI | 해석 |
|---|---|---|---|
| `river_view` | **+30.9%** | [+25.2, +36.9] | 한강 본류 조망 프리미엄. 강하고 좁다 |
| `mountain_view` | −10.7% | [−15.2, −6.0] | **부호 역전.** 외곽 proxy 의심. 원인 미분리 |
| `open_span_max` | −0.05%/도 | [−0.09, −0.01] | 개방도 3종이 서로 상관 −0.92, VIF 9.15 — 개별 해석 불가 |
| `sun_hours_winter` | +0.59%/시간 | **[−0.38, +1.58]** | **결론 불가.** §6 참조 |

## 6. 표기 규칙 — 어기면 사실 왜곡

`data-contract.md` §6의 기존 규칙에 아래를 추가한다.

| 쓸 수 있다 | 쓸 수 없다 |
|---|---|
| "이 단지 이 면적의 최근 거래는 14.2억입니다" | "적정시세는 14.2억입니다" |
| "한강 조망 단지는 평균 31% 높게 거래됩니다" | "이 집은 조망 때문에 3억 비쌉니다" |
| "비슷한 조건 단지 5곳의 최근 거래는 12~15억입니다" | "이 집은 저평가입니다" |
| "일조가 가격에 미치는 영향은 확인되지 않았습니다" | "일조는 가격에 반영되지 않습니다" |

**일조에 대해 특히 주의한다.** p = 0.23은 "효과 없음"의 증거가 아니라 "증거 없음"이다.
신뢰구간이 시간당 +1.58%까지 열려 있어, 3시간 차이에서 약 +4.5% 프리미엄도 배제하지 못한다.
"시장이 일조에 값을 매기지 않으니 공짜로 얻으라"는 서사는 데이터가 뒷받침하지 않으므로 금지한다.

우리가 말할 수 있는 것은 여기까지다:

> 최근 실거래가는 가격의 가장 강한 기준점이다. 임앤장은 실거래가만으로 확인할 수 없는
> 일조와 조망을 물리적으로 계산해 주거 선택 정보를 보완한다.

## 7. 비교사례 제시 규칙

"비슷한 환경의 다른 곳은 보통 이 가격" 문장을 만들 때:

- 동일 단지 → 인근 유사 단지 순으로 찾는다. 면적·연식·규모·지역을 먼저 제한하고 환경 유사도는 그 다음이다
- **개수를 채우지 않는다.** 적합한 사례가 2곳이면 2곳만 보여준다
- 원 거래가·거래일·보정액·선정 이유를 함께 표시한다. 보정폭이 큰 사례는 제외한다
- 보정가격은 실제로 체결된 가격이 아니라는 것을 화면에 명시한다

## 8. 대회 제출에 쓸 수 있는 숫자

셋 다 누수 없는 out-of-time 검증에 ablation과 구간 추정을 갖췄다.

1. 단지 이력이 없는 cold-start 구간에서 baseline 대비 MAPE **70.3% → 23.3%** (전체 거래의 5.8%)
2. 한강 조망 **+30.9% [25.2, 36.9]** — 자체 물리 엔진이 만든 feature가 시장 가격을 설명
3. 물리 feature 전체 **ΔR² +0.079**, bootstrap CI가 0을 배제

**SHAP는 이번 제출에서 쓰지 않는다.** 상관된 feature에 대한 attribution은 배경 설정에 따라
달라지고 인과를 뜻하지 않는다. 설명은 실제 비교사례와 환경 원값으로 한다.

**런타임 생성형 AI는 0회를 유지한다.** 대회 공식 요건에 생성형 AI 의무가 없으므로 감점도
가점도 아니다. 기술력 축은 물리 시뮬레이션과 위 세 숫자로 세운다.
